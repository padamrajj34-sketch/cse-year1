# Week 1 Pseudocode Problems

## 1. Add Two Numbers
1. Read the first number A.
2. Read the second number B.
3. Calculate `sum = A + B`.
4. Print `sum`.

## 2. Find the Largest of Three Numbers
1. Read three numbers A, B, and C.
2. If A >= B and A >= C, print A.
3. Else if B >= A and B >= C, print B.
4. Else, print C.

## 3. Check if a Number is Even or Odd
1. Read a number N.
2. Find the remainder of N divided by 2 (`N % 2`).
3. If the remainder is 0, print "Even".
4. Else, print "Odd".
